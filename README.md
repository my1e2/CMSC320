# CMSC320 — Introduction to Data Science

A comprehensive repository containing coursework, programming assignments, datasets, lecture materials, and exploratory analyses completed for CMSC320 / DATA320: Introduction to Data Science.

---

## Overview

This repository documents my work throughout CMSC320, covering topics including:

* Data collection and cleaning
* Exploratory data analysis (EDA)
* Statistical analysis
* Data visualization
* Machine learning fundamentals
* Neural networks
* Classification and regression
* Ethics in data science

The repository includes programming assignments, written assignments, lecture notebooks, datasets, and supporting course materials used throughout the semester.
